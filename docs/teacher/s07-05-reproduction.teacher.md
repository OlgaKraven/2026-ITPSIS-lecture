## 16. Гипотеза

<!-- source-slides: s07-05-reproduction-Q01-term -->

В нашем эпизоде наблюдаем следующее: Факт: HTTP 503 после отправки; гипотеза: ограничение очереди на крупное вложение. По первому вопросу важно условие: До проверки фиксируют то, что увидел пользователь, не подменяя факт техническим объяснением. По последнему проверяем: Получатель повторяет симптом и понимает происхождение каждого файла. Если переносим решение из CampusHelp в другую организацию, сначала уточняем её услугу, ограничения и критерии приёмки. Воспроизведение помогает проверить гипотезу, но не должно задерживать безопасное восстановление критической услуги. Детальные эксперименты выполняются в изолированной среде; связь с инцидентом сохраняется в пакете доказательств. Неясные условия фиксируем как вопрос для уточнения, а не заменяем догадкой. На этом завершаем лекцию; дальнейшая работа: подготовить пакет для эскалации без повторного опроса пользователя.
