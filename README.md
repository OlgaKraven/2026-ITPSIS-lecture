# МДК.06.02 — поддержка и сопровождение информационных систем

[Курс](https://olgakraven.github.io/2026-ITPSIS-lecture/) · [Инструкция](https://olgakraven.github.io/2026-ITPSIS-lecture/guide.html)

15 лекций для 7-го и 8-го семестров; 120 вопросов, 1843 слайда, 480 заданий самопроверки и 120 самостоятельных учебных случаев. Все 1723 слайда предыдущей редакции сохранены с прежними ID и порядком; добавлены паспорта самостоятельных случаев перед тестами каждого вопроса. Условия CampusHelp, сроки и пороги являются учебными данными. Часы, компетенции и персональные данные преподавателя не назначены.

Каталог, обе темы, титул и два окна используют утверждённый дизайн от 22 октября 2026 года. В каталоге доступны карточки и список, поиск, семестры, QR материалов и профиль преподавателя. В лекции основные команды находятся в компактной шапке, дополнительные — в «Ещё». «Режим показа», полный экран и указка действуют независимо.

У каждого вопроса свой самостоятельный случай: прогноз, ручное изучение наблюдений, выбор обоснованного вывода, проверка и отдельный разбор. Свободный текст не получает автоматическую оценку. Черновик сохраняется для ID и редакции условия. Основные 480 заданий и их ключи сохранены; совместимые позиции и черновики прежней редакции переносятся без удаления старых данных.

## Преподавателю

Сценарий автоматически загружается для текущей лекции при открытии панели преподавателя. Все пять полей заполнены для 1843 слайдов. Личные непустые записи прежних редакций сохраняются; явные изменения и очистка полей имеют приоритет над опубликованным текстом. При ошибке загрузки доступна повторная попытка. Заметки загружаются только панелью преподавателя; аудитория и PDF их не запрашивают. Публичный авторский сценарий доступен по прямым адресам, как было согласовано ранее.

Редактируемые тексты, сценарии и карты с SHA-256 находятся в `docs/teacher/`; канонический пакет — `authoring/teacher-notes.json`. Экспорт личных записей: «Сохранить заметки» в панели преподавателя.

## Разработка

Node.js 22.18+; локально проверяется Node.js 24.21.0. Рабочий движок теперь хранится в `src/engine/`, поэтому проверки и приложение используют один исходный код. Происхождение переноса описано в `vendor/README.md`. Старые исходники в `src/components/` и `src/deck/` сохранены как история исходного курса и не являются точкой входа приложения.

```sh
npm ci
npm run dev
npm run compile:content
npm run prepare:notes
npm run generate:teacher
npm run lint
npm test
npm run spellcheck
npm run build
npx playwright install chrome
npm run test:e2e
```

`authoring/audit-upgrade.mjs` применяет содержательные уточнения при компиляции; `authoring/transfer-cases.mjs` содержит 120 отдельных случаев. После изменения слайдов нужно актуализировать канонический сценарий, затем повторить проверки и сборку. `authoring/audit-baseline.json` закрепляет ID и ключи предыдущей редакции. Основные определения в «Запишите» согласованы с преподавательскими заметками.

## PDF

```sh
PDF_OUTPUT_DIR=public/pdf npm run export:pdf
PDF_OUTPUT_DIR=public/pdf npm run check:pdf
npm run build
```

В `public/pdf/` находятся 15 файлов из рендерера сайта. В них сохраняются условия заданий, схемы, литература и ссылки, без попыток и преподавательского разбора. Ссылки на самостоятельные дополнения используют адрес GitHub Pages, а не локальный сервер экспорта. Для проверки компоновки всех страниц в двух темах запустите локальный сервер и `node scripts/check-layout.mjs`; адрес меняется переменной `AUDIT_BASE`.

GitHub Actions проверяет и публикует `dist` из `main`. Результат текущего аудита и фактические границы проверок — в [отчёте](reports/AUDIT-2026-10-23.md). Полная утверждённая РПД и часы не переданы; время сценария является оценкой полного маршрута, а не расписанием. Физический проектор и другие ОС проверяются отдельно.
