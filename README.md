# МДК.06.02 — поддержка и сопровождение информационных систем

[Открыть лекционный сайт](https://olgakraven.github.io/2026-ITPSIS-lecture/)

![Каталог курса](public/og.png)

15 переработанных лекций для 7-го и 8-го семестров, **120 сохранённых учебных вопросов, 1573 веб-слайда, 480 заданий**. В каждой лекции 104–105 слайдов, восемь вопросов и 32 задания. Семестр 7 содержит 10 лекций, семестр 8 — пять. Названия лабораторных сохранены для связи с лекциями; отдельный лабораторный курс не разрабатывался.

Теория и авторские примеры CampusHelp дополнены практиками **ITIL 4**: служба поддержки, инциденты, запросы, проблемы, изменения, уровни услуг, знания, мониторинг, конфигурация и восстановление. Наличие **ITIL (Version 5)** обозначено отдельно: версии не смешиваются. Числа и процедуры CampusHelp являются учебными условиями, а не нормативами ITIL.

## Основа и данные

Используется пакет `@olgakraven/lecture-engine` **0.1.0**, собранный из [шаблона](https://github.com/OlgaKraven/2026-lecture-shablone/tree/5a1f9732937a8774fad135af2c99faf1b49ba7c2). Архив сохранён в `vendor/`; проигрыватель и его CSS не переписаны для курса. Пакет устанавливается по lock-файлу, без зависимости от меняющейся ветки шаблона.

- `public/course.json` — единственный источник ученического содержания для просмотра и печати.
- `public/assessment.json` — автономный учебный банк. Ответы технически доступны посетителю; это не защищённый экзамен.
- `authoring/original-course.json` — снимок исходного курса, коммит `5eb874a338637f90e0d6e90064bc95af0cf933e0`.
- `authoring/itil-context.mjs`, `authoring/worked-results.mjs` — предметные дополнения и образцы решений.
- `authoring/question-map.json`, `migration-map.json`, `glossary.json`, `sources.json` — карта вопросов, перенос всех 1275 исходных слайдов, словарь и источники.
- `src/data/`, `src/deck/` и прежние компоненты сохранены как исходный материал миграции; новая точка входа их не загружает. Старые модульные тесты контролируют неизменность исходного состава курса.

Для правок содержания измените авторские исходники, выполните `npm run compile:content`, затем проверки и сборку. Компилятор заменяет производные JSON: не редактируйте их независимо. Изменение опубликованного содержания требует новой `contentVersion` и соответствующего преподавательского комплекта. История старых попыток не переносится в новые задания. Старые ссылки `?topic=...&slide=...` переводятся через явную карту переноса.

## Запуск и проверки

Node.js 22.18+ и npm; локальная проверка выполнена на Node.js 24.11.1.

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run test
npm run spellcheck
npm run build
npx playwright install chrome
npm run test:e2e
npm run preview
```

`npm run test` включает 21 проверку исходного курса, расширенную проверку структуры и 1922 случая оценивания, пять тестов протокола и оценивания движка. Браузерные проверки используют production-сборку. `spellcheck` — проверка ограниченного списка ошибок и повторов, не полная лингвистическая экспертиза. `check:privacy` проверяет сборку и, при наличии локального комплекта, все полные сценарии.

## Занятие и преподавательский комплект

В настройках укажите ФИО, должность и подразделение: они сохраняются на этом устройстве. Затем откройте лекцию и нажмите «Начать занятие в двух окнах». В панели преподавателя выберите **«Загрузить заметки»** и импортируйте отдельно переданный `teacher-pack.json` версии `2026-09-12-itil-1`. Полный комплект содержит 1573 заметки; его импорт и восстановление после перезагрузки проверены в Chrome.

Файл сценария, карточки подготовки и производный `teacher.md` **не публикуются в этом репозитории или сайте**. Сохраняйте экспорт перед объединением собственных заметок с новой редакцией: импорт шаблона объединяет записи по ID. Окно аудитории получает текущий материал и управляемую попытку, без полных заметок и банка ключей. Физический второй монитор переносится вручную.

## PDF

В каталоге доступна печать каждой лекции; в настройках — семестра и всего курса. Один слайд соответствует странице 16:9. Печатное представление не включает попытки, ответы или сценарий.

```sh
npm run build
npm run export:pdf
npm run check:pdf
```

Экспорт использует Chrome и тот же рендерер. Файлы создаются в `outputs/pdf/`; переменная `PDF_OUTPUT_DIR` позволяет выбрать другую папку. Готовые ученические файлы данной редакции находятся в [public/pdf](public/pdf). При изменении содержания пересоздайте PDF перед публикацией.

## Проверка и ограничения

[Отчёт качества](reports/QUALITY.md), [реестр](reports/registry.json), [ход работы](reports/PROGRESS.md).

Полная утверждённая РПД, часы, компетенции, ФИО и учебный год не переданы. Сохранены доступные исходные темы; соответствие неизвестным часам не заявляется. Расчёт полного маршрута составляет примерно 165–176 минут на лекцию, включая запись и задания; это оценка работы, не утверждённое расписание.

Проверены открытые первичные описания ITIL PeopleCert. Закрытые Practice Guides и тексты платных учебников не использованы как прочитанные источники. Аппаратная проверка с физическим проектором не проводилась.

## Публикация

GitHub Actions из `.github/workflows/pages.yml` публикует `dist/` после проверок. Базовый путь: `/2026-ITPSIS-lecture/`. Изменения относятся к этому курсу; репозиторий шаблона не изменяется. Open Graph использует превью каталога; отдельная настройка GitHub Social preview не менялась.
